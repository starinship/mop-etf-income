# MOP 固定收益 ETF 組合追蹤

給 Mo Star（澳門）使用的單檔 HTML 工具，用來追蹤 **JEPQ / JEPI / SCHD** 目標配置（50% / 30% / 20%）。

本倉庫只存放程式頁面，**不含持倉、股息或任何個人資料**。所有輸入會自動存在你開啟此頁的那一個裝置、那一個瀏覽器裡。

## 如何開啟

1. 下載本倉庫的 `index.html`
2. 用 Chrome / Edge / Safari / Firefox 開啟（電腦可直接雙擊或拖進瀏覽器）
3. 無需安裝、無需連線亦可繼續使用（更新股價時除外）

## 使用方式

- **概覽卡片**：總成本、現市值、未實現損益、預估月息（稅前／稅後 30%）
- **持倉表**：可改股數、均成本、現價、殖利率；按「依目標金額估算股數」依目標 MOP ÷ 匯率 ÷ 現價填入
- **股息紀錄**：新增每月股息；選「再投入」可自動加股
- **再平衡**：顯示相對 50/30/20 誰偏低，並建議下月股息優先投入
- **回本試算**：輸入稅後殖利率與股價年變動，估算股息回本年數與連本帶利
- **匯出／匯入 JSON**：備份或換裝置時使用；「重設為目標計劃」可還原預設

## 資料儲存

- 自動存於瀏覽器 `localStorage`，鍵名：`mop-etf-income-v1`
- 資料**只留在此瀏覽器**，不會上傳到 GitHub
- 清除網站資料會遺失紀錄，請定期「匯出 JSON」備份
- 換電腦、換手機或換瀏覽器時，用「匯入 JSON」還原
- 若用網址開啟（例如日後啟用 GitHub Pages），同一瀏覽器會沿用同一份資料；若改為本機開啟檔案，則是另一份本機資料

## 預設假設

- 匯率：7.8 MOP / USD（可改）
- 券商備註：螞蟻銀行（澳門）美股；美國股息預扣約 30%
- 現價／殖利率為可編輯參考值，請自行更新
