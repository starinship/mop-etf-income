# MOP 固定收益 ETF 組合追蹤

私人使用的單檔 HTML 工具，用來追蹤 **JEPQ / JEPI / SCHD** 目標配置（50% / 30% / 20%，總資本 MOP 1,000,000）。此儲存庫維持私人，請勿公開。

## 如何開啟

1. 在檔案總管找到根目錄的 `index.html`
2. **雙擊**以預設瀏覽器開啟，或把檔案**拖曳**進 Chrome / Edge / Safari / Firefox
3. 無需安裝、無需建置；離線亦可使用

## 使用方式

- **概覽卡片**：總成本、現市值、未實現損益、預估月息（稅前／稅後 30%）
- **持倉表**：可改股數、均成本、現價、殖利率；按「依目標金額估算股數」依目標 MOP ÷ 匯率 ÷ 現價填入
- **股價日記**：按「用現價寫入今日股價」，把持倉表上的 JEPQ／JEPI／SCHD 現價寫成當日 USD 快照；同一天再按會覆寫。歷史表可刪列，並顯示相對上一筆的漲跌
- **股息紀錄**：新增每月股息；選「再投入」可自動加股
- **再平衡**：顯示相對 50/30/20 誰偏低，並建議下月股息優先投入
- **回本試算**：輸入稅後殖利率與股價年變動，估算股息回本年數與連本帶利
- **匯出／匯入 JSON**、**重設為目標計劃**：備份、換裝置，或還原預設

## 資料存在哪裡

- 自動存於**此瀏覽器**的 `localStorage`，鍵名：`mop-etf-income-v1`
- 舊版若沒有股價日記欄位，開啟時會補上空的 `priceLog`，持倉與股息紀錄會保留
- 這些數字**不會**進 Git。儲存庫只有頁面程式與說明；請勿把匯出的 JSON 提交進來
- 清除網站資料會遺失紀錄，請定期「匯出 JSON」備份
- 換電腦或換瀏覽器時，用「匯入 JSON」還原

## 預設假設

- 匯率：7.8 MOP / USD（可改）
- 券商備註：螞蟻銀行（澳門）美股；美國股息預扣約 30%
- 現價／殖利率為可編輯參考值，請自行更新
