# MOP 固定收益 ETF 組合追蹤

給 Mo Star（澳門）使用的單檔 HTML 工具，用來追蹤 **JEPQ / JEPI / SCHD** 目標配置（50% / 30% / 20%）。持倉金額、股數與成本請按實際自行填入；本倉庫只存放頁面，不含個人持倉資料。

線上頁面：[https://starinship.github.io/mop-etf-income/](https://starinship.github.io/mop-etf-income/)

## 如何開啟

- 用上方網址在瀏覽器開啟（資料只存在該裝置的瀏覽器）
- 或下載 `index.html` 後雙擊以本機檔案開啟；`file://` 與網頁版是不同來源，資料不會自動共用，需用「匯出／匯入 JSON」轉移

## 使用方式

- **概覽卡片**：總成本、現市值、未實現損益、預估月息（稅前／稅後 30%）
- **持倉表**：請按實際填入目標金額、股數與均成本；匯率、現價、殖利率已預填，可再按市況修改。若先填目標 MOP，可按「依目標金額估算股數」試算
- **股息紀錄**：新增每月股息；選「再投入」可自動加股
- **再平衡**：顯示相對 50/30/20 誰偏低，並建議下月股息優先投入
- **回本試算**：輸入實際起始本金、稅後殖利率與股價年變動，估算股息回本年數與連本帶利
- **匯出／匯入 JSON**：備份或換裝置時使用；「重設資料」會清除已填持倉並還原匯率與參考行情

## 資料儲存

- 自動存於瀏覽器 `localStorage`，鍵名：`mop-etf-income-v1`
- 資料**只留在此瀏覽器**；清除網站資料會遺失，請定期「匯出 JSON」備份
- 換電腦或換瀏覽器時，用「匯入 JSON」還原

## 預設假設

- 匯率：約 8.08 MOP / USD（2026-11-16 參考，可改）
- 現價／殖利率為 2026-11-13 收市參考值，請自行核實更新
- 券商備註：螞蟻銀行（澳門）美股；美國股息預扣約 30%
- 不預填目標金額、股數、均成本或起始本金
